# 如何抓日志并发给开发者

当你反馈「定位没反应」「闪退」这类问题时，日志能直接指出卡在哪一步。
下面三种方式**任选一种**即可。

---

## 方式一：一键脚本（推荐，最简单）

1. 用数据线把手机连到电脑；
2. **双击 `tools/` 目录下的 `抓日志.bat`**（它会调用同目录的 `log-tool.ps1`，两个文件都要在）；
3. 按窗口提示操作：
   - 若提示没检测到手机 → 按窗口里列的 5 条检查（多半是没开「USB 调试」或没在手机上点「允许」）；
   - 检测到手机后，脚本会**先清空旧日志**，然后让你去手机上复现问题；
4. 在手机上依次操作（每步停 2-3 秒）：
   1. 打开「定位打卡」，确认**版本号是 1.7.2**；
   2. 进「设置 → 定位调试」，点「单次定位」；
   3. 打开某个打卡点，点「定位到当前位置」；
   4. 回设置页点「开始监控」；
   5. 如果闪退了，重新打开 App 继续；
5. 回到电脑窗口，**按回车**；
6. 脚本会自动弹出 `logs` 文件夹，把里面的 **`checkin-log.txt`** 发我；
   - 如果窗口提示「检测到崩溃相关内容」，把 **`crash-log.txt`** 也一起发。

脚本还会在窗口里直接打印「关键信息摘要」，包括：
- 已安装的版本号（确认你装的确实是新版）
- 高德 SDK 初始化日志（能看到 `隐私已同意=true/false`）
- 定位成功/失败与错误码
- 崩溃堆栈

---

## 方式二：手动命令

如果没有脚本或想自己来，在工程目录打开 PowerShell：

```powershell
$adb = "C:\Android\Sdk\platform-tools\adb.exe"

# 1. 确认手机已连上（应看到一行 xxxxx  device）
& $adb devices -l

# 2. 清空旧日志
& $adb logcat -c

# 3. 现在去手机上复现问题（重复操作几遍）

# 4. 导出日志到文件
& $adb logcat -d -v time > "$HOME\Desktop\checkin-log.txt"

# 5. 另外把崩溃日志也导一份
& $adb logcat -b crash -d -v time > "$HOME\Desktop\crash-log.txt"
```

然后把桌面上的这两个 txt 发我。

---

## 方式三：只想看几条关键日志（快速自查）

```powershell
$adb = "C:\Android\Sdk\platform-tools\adb.exe"

# App 启动时高德 SDK 的初始化与「隐私是否已同意」
& $adb logcat -d | Select-String "CheckinApp"

# 定位成功/失败与错误码
& $adb logcat -d | Select-String "AMapLocationEngine|LocationError|Locator"

# 闪退堆栈（最重要）
& $adb logcat -b crash -d
```

---

## 手机连不上电脑时（本机抓日志）

不想用数据线，也可以让手机自己抓：

1. 打开手机「设置 → 关于手机」，连点 7 次「版本号」打开开发者选项；
2. 「开发者选项 → 错误报告 / 生成错误报告」；
3. 等生成完成后，会提示保存位置（一般在 `内部存储/` 或通知栏可直接分享）；
4. 但**错误报告压缩包里文件很多**，不便直接阅读。

> 所以还是**推荐用数据线 + 方式一**，脚本已经把关键信息提炼好了。

---

## 我需要日志里的什么

| 我要判断的问题 | 对应日志关键字 |
| --- | --- |
| 你装的到底是不是新版 | 窗口摘要里的 `versionName`（应为 1.7.2） |
| 高德隐私合规是否生效 | `高德 SDK 初始化：... 隐私已同意=？` |
| Key / 包名 / SHA1 是否匹配 | `定位失败 code=26` |
| 隐私未同意（旧版 bug） | `定位失败 code=27` |
| 定位服务未开 | `定位失败 code=18` |
| 闪退原因 | `AndroidRuntime: FATAL EXCEPTION` 后面的完整堆栈 |

---

## 发送方式

- **直接把 `.txt` 文件拖进聊天窗口**（推荐）；
- 或用记事本打开后复制内容粘贴给我。

> 日志里可能包含你的打卡点名称与大致坐标，**发送前可自行删掉不放心的地方**，
> 我只需要 `CheckinApp`、`AMapLocationEngine`、`AndroidRuntime` 这几类标签的内容。
